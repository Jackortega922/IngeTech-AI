# 🖥️ PC EXPERT — Sistema Inteligente de Recomendación y Armado de PC

PC EXPERT es una aplicación de escritorio desarrollada en **Python + Tkinter** que permite:

- Recomendación automática de componentes según presupuesto.
- Búsqueda avanzada de hardware (CPU, GPU, RAM, SSD, placa madre, etc.).
- Verificación de compatibilidad entre componentes.
- Armado de PC paso a paso.
- Exportación del resultado en **PDF** o **TXT**.
- Motor de aprendizaje que registra elecciones del usuario.
- Instalador mediante PyInstaller (EXE) y soporte para MSI.
